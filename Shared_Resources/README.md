# Shared Resources

This folder contains shared templates, datasets, and other reusable resources that support collaboration and learning within the Alliance Hub.

## Contents
- **Templates**: Pre-built templates for Jupyter Notebooks and LaTeX documents to maintain consistency across contributions.
- **Datasets**: General-purpose datasets that can be used for experimentation or analysis.

## How to Use
- **Templates**:
  - Use the `notebook_template.ipynb` to ensure your Jupyter Notebooks follow a consistent structure.
  - Use the `notes_template.tex` for creating well-formatted LaTeX notes.
- **Datasets**:
  - Download the datasets and use them in your notebooks or projects.
