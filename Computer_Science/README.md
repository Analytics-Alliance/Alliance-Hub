# Computer Science

This folder contains resources to build a strong foundation in Computer Science.

- **Notebooks**: Hands-on coding examples and algorithm demonstrations.
- **Notes**: Written guides, topic overviews, and study material.

---

## Subfolders

- [Notebooks](./Notebooks): Interactive notebooks for coding and algorithm demonstrations.
- [Notes](./Notes): Written explanations and study guides on CS topics.

---

## Contribution Guidelines

To contribute:
1. Add Jupyter Notebooks to the `Notebooks` subfolder with clean code and comments.
2. Add notes or written guides to the `Notes` subfolder. Use a structured format.
3. Use filenames that clearly indicate the content (e.g., `sorting_algorithms.ipynb` or `operating_systems_notes.md`).

Help us create a comprehensive hub for Computer Science!
